# Vasu Portfolio

Personal portfolio website for Vasu Yadav, ServiceNow Developer & Product Engineer.

**Live Site**: https://kvvasu.github.io/Vasu_Now

## Description

A ray-traced black hole themed portfolio featuring:
- Interactive WebGL black hole with gravitational lensing effects
- Draggable singularity with geodesic ray tracing
- Theme toggle (dark/light with persistent storage)
- Cycleable accretion disk presets (zen, quasar, gargantua)
- Responsive design with reduced-motion support
- Accessible with skip links, focus-visible outlines, and semantic HTML

## Technologies

- HTML5 with CSS custom properties
- Vanilla JavaScript WebGL ray tracing
- CSS media queries for responsive behavior
- `prefers-reduced-motion` and `forced-colors` media queries
- LocalStorage-based theme persistence

## Sections

- **Hero**: Interactive black hole with ray tracing physics
- **Profile**: Name, role, availability, contact actions
- **Biography**: /now and /connect sections
- **Footer**: Copyright and location
